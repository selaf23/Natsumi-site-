Política de Privacidad

Natssumi Sniper · Última actualización: 3 de noviembre de 2026

Esta Política explica qué información procesa Natssumi Sniper (la “Aplicación”) y cómo se utiliza.

1. Información que procesamos

  • Publicaciones públicas de X: identificadores de posts, handles, texto público, timestamps y direcciones de contratos mencionadas.
  • Datos técnicos de funcionamiento: logs, errores, latencia, estado de conexión y dirección pública de la wallet de trading.
  • No solicitamos correo electrónico, teléfono, contraseña de X ni acceso a mensajes directos.
  • No creamos cuentas de usuario ni almacenamos credenciales de usuarios de X.

2. Para qué se usa

  • Detectar publicaciones públicas de handles autorizados y procesar señales relacionadas.
  • Operar, mantener y depurar la Aplicación.
  • Cumplir obligaciones legales o atender requerimientos válidos.

3. Base y minimización

Procesamos únicamente información pública y datos técnicos necesarios para operar la Aplicación. No vendemos datos personales ni los usamos para publicidad.

4. Terceros

La Aplicación utiliza la API de X y proveedores de infraestructura/hosting. Estos proveedores pueden procesar datos técnicos conforme a sus propias políticas. Las operaciones blockchain son públicas por naturaleza.

5. Conservación

Los logs técnicos y eventos se conservan solo durante el tiempo necesario para operar, auditar y resolver errores. Los datos públicos de X pueden eliminarse o dejar de procesarse cuando el post se elimina o cuando ya no son necesarios.

6. Seguridad

Aplicamos medidas razonables para proteger credenciales y datos técnicos. Ningún sistema es 100% seguro; no garantizamos seguridad absoluta.

7. Derechos y contacto

Puedes solicitar información, corrección o eliminación de datos técnicos que podamos conservar escribiendo a Julito_stebanospin@gmail.com.

8. Menores

La Aplicación no está dirigida a menores de edad y no solicita datos de menores.

9. Cambios

Podemos actualizar esta Política. La versión vigente se publicará en esta página con su fecha de actualización.
