Términos de Servicio

Natssumi Sniper · Última actualización: 3 de noviembre de 2026

Estos Términos regulan el uso de Natssumi Sniper (la “Aplicación”), una herramienta de automatización que lee publicaciones públicas de X mediante la API oficial y procesa direcciones de contratos y señales relacionadas.

1. Descripción del servicio

La Aplicación es una herramienta técnica de solo lectura sobre X. No publica contenido, no interactúa con usuarios, no envía mensajes directos y no requiere que los usuarios inicien sesión con su cuenta de X.

2. No es asesoría financiera

La Aplicación no ofrece asesoría financiera, legal, contable ni de inversión. Las señales, datos o resultados son informativos y no constituyen una recomendación de compra o venta. Los activos digitales son volátiles y puedes perder todo el capital invertido.

3. Uso permitido

  • Usar la Aplicación de forma lícita y conforme a las reglas de X y de los proveedores externos.
  • No intentar evadir suspensiones, límites de API, controles de acceso o medidas de seguridad.
  • No usar la Aplicación para spam, manipulación, acoso, suplantación o actividades ilegales.
  • No crear cuentas o aplicaciones para eludir sanciones de X.

4. Servicios de terceros

La Aplicación depende de X, proveedores de infraestructura y redes blockchain. No controlamos su disponibilidad, exactitud, latencia, cambios de API o decisiones de suspensión. El uso de X se rige además por sus propios términos y políticas.

5. Sin garantías

La Aplicación se proporciona “tal cual” y “según disponibilidad”. No garantizamos funcionamiento ininterrumpido, ausencia de errores, exactitud de datos, disponibilidad de liquidez ni resultados de trading.

6. Limitación de responsabilidad

En la medida permitida por la ley, no seremos responsables por pérdidas directas o indirectas, daños, lucro cesante o pérdida de datos derivados del uso o imposibilidad de uso de la Aplicación.

7. Cambios

Podemos actualizar estos Términos para reflejar cambios técnicos o legales. La versión vigente se publicará en esta página con su fecha de actualización.
